# Rewind 機能 実装計画

Nintendo Switch の EGG CONSOLE が提供している「数秒前に戻れる巻き戻し機能」を Bubilator88 に追加するための設計メモ。

## 仕組み（リングバッファ式リワインド）

1. **エミュ駆動中、N 秒ごと（例: 0.5 秒）にステート全体をシリアライズしてリングバッファに push**
   - 既存の `SaveState` / `SaveStateSerialize` をそのまま流用（ディスクには書かず in-memory `Data`）
   - 容量上限: 例 10 秒分 = 20 スロット、20 秒なら 40 スロット
2. **巻き戻しキー（例: Backspace 長押し or 専用ボタン）**
   - 押下中: リングバッファを末尾から先頭へ向けて 1 スロットずつロード → 「逆再生」風に見える
   - 離すとその時点のステートでエミュ再開
3. **画面サムネイル付き**: 各スロットに 320×200 などの低解像度 RGBA も保存しておくと、巻き戻し中の "コマ送り" 表示がスムーズ

## コスト見積もり

- 1 ステート ≒ 数百 KB〜1 MB（メイン RAM 64K + GVRAM 48K + サブ RAM 16K + YM2608 内部 + 残り）
- 0.5 秒間隔 × 30 秒 = 60 スロット → **〜60 MB**。許容範囲
- 圧縮（zlib/lz4）すれば 1/3〜1/5 に縮む。RAM はゼロ埋め部分が多いので圧縮効率は高い
- シリアライズ自体のコストが 60 fps を割らないか要計測。重ければ専用 utility queue へオフロード

## 設計ポイント

- **スナップショット間隔 vs 粒度のトレードオフ**: 0.5 秒なら 60 スロット/30 秒で軽量。0.1 秒だと滑らかだが容量 5 倍
- **音声**: 巻き戻し中は AudioOutput を mute（または音声バッファもリングに乗せて逆再生）。最低限 mute が無難
- **録音/録画との排他**: AudioRecorder / VideoRecorder と同様に `isRewinding` で互いに無効化
- **入力**: 巻き戻し中はキーマトリクス入力を止める。離した瞬間の状態から再開なので、押しっぱなしキーの handling を考慮（ロード後に押下中キーを残すか全リリースか）
- **CPU 負荷**: シリアライズは emuQueue 上で同期、または「N tick ごとにコピー → 別 queue でエンコード」の二段。ProRes ビデオ録画と違い、**60Hz の枠内で数百 KB の memcpy** なので emuQueue 内同期でも実用的
- **ホットキー**: SwiftUI menu に "Rewind" を追加 + `keyboardShortcut`。押しっぱなし検知は `KeyEventView` で onKeyDown / onKeyUp フック
- **UI**: ステータスバーに巻き戻し中インジケータ。サムネイル時系列を半透明オーバーレイで横スクロール表示するのもアリ（EGG CONSOLE の演出に近い）

## 既存コードとの接続

- `SaveStateSerialize.swift` の Codable 構造をそのまま `Data` 化 → リングバッファ保管
- `EmulatorViewModel.loadStateFromData(_:)` 相当を呼ぶ（既存実装があるなら流用、無ければ追加）
- `EmulatorMetalView.draw()` 内のフレーム生成箇所で「N フレームごとに snapshot」を判定。`videoRecorder.appendFrame` と並ぶ位置に置ける

## MVP 段階案

1. **Phase 1**: 0.5s 間隔・30 秒分のリングバッファ＋ホットキー押下で「N 秒前まで一気に戻る」（連続再生なし）
2. **Phase 2**: 押しっぱなしで連続コマ送り逆再生
3. **Phase 3**: サムネイルストリップ UI、圧縮、AudioOutput リバース

## トレードオフ / 注意

- **サブシステム同期**: ステートロード時に PIO ハンドシェイクや FDC コマンド進行中だと、ロード後に整合性が取れる前提。既存セーブステートが動いていれば OK
- **FDD アクセス中の巻き戻し**: 物理的なディスク読み込みは emulator 内なので問題ないが、ディスク D88 への書き込み（上書きセーブ等）は巻き戻しで「なかったこと」にできない。`Settings.shared.writeProtectByDefault` 的な抑制と組み合わせるのが安全
- **特殊な装置**: 録音/録画/ステートロード/ディスクマウントが進行中は rewind を無効化

## 推奨スタート地点

まずは MVP（Phase 1 だけ）で 0.5s 間隔 × 10 秒（20 スロット, 〜20MB）から実装するのが現実的。
