CD-ROM

PC-8801MC の CD-ROM ドライブを使い、CD 版のソフトを起動できます。

準備

PC-8801MC の CD BIOS を CDBIOS.ROM（64KB）として ~/Library/Application Support/Bubilator88/ に置きます。

CD-ROM ドライブは、CD が入った状態でリセットしたときにつながっているものとして動きます。CD が入っていなければドライブはなく、これまでどおり BASIC かディスクから起動します。

対応フォーマット

  • .cue — キューシート。1 ファイルにまとめたイメージも、トラックごとのファイルも開けます。
  • .ccd — CloneCD 形式。同じ名前の .img と組で使います。

どちらも、セクターを 2352 バイトのまま収めたイメージに限ります。.iso や MODE1/2048 のトラックには対応していません。イメージのファイルは CD を入れている間に読み出すので、移動や削除をしないでください。

CD を開く

操作内容
CD > 開く...CD を入れ、V2 モード・8MHz に切り替えてリセットし、CD から起動します
CD > 取り出しCD を取り出します
CD > 最近使ったファイル最近開いた CD を最大 10 件までたどれます

画面に .cue / .ccd をドラッグ＆ドロップしても開けます。設定 > 表示 > ステータスバー > CD アイコンを表示 をオンにすると、ステータスバーに CD 名とアクセスランプが出ます。

CD 版のソフトの多くはフロッピーディスクも使います。ソフトがブランクディスクを求めたら、ディスク > 空ディスク作成... で作って入れてください。

音楽

CD の音楽（CD-DA）は FM 音源と同じ出力に混ぜて鳴らします。ソフトが指示するフェードイン・フェードアウトにも従います。イマーシブオーディオでは、CD の音楽は立体配置せず、中央からステレオで鳴ります。

ステートセーブ

ステートには再生位置などドライブの状態が入りますが、CD の中身は入りません。ステートを読み込むと、保存したときの CD を同じ場所から入れ直します。見つからないときは CD を取り出した状態になります。
