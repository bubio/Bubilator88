CD-ROM

With the PC-8801MC's CD-ROM drive you can boot CD releases.

Setup

Put the PC-8801MC CD BIOS in ~/Library/Application Support/Bubilator88/ as CDBIOS.ROM (64KB).

The CD-ROM drive is connected whenever the machine resets with a CD in it. With no CD there is no drive, and the machine boots to BASIC or the disk as before.

Supported Formats

  • .cue — cue sheet, for a single image or one file per track.
  • .ccd — CloneCD, with the .img of the same name.

Both must hold raw 2352-byte sectors; .iso and MODE1/2048 tracks are not supported. The image is read while the CD is in, so do not move or delete it.

Opening a CD

ActionWhat it does
CD > Open...Inserts the CD, switches to V2 mode at 8MHz, resets and boots from it
CD > EjectTakes the CD out
CD > Recent FilesUp to 10 recently opened CDs

You can also drop a .cue or .ccd on the screen. With Settings > Display > Status Bar > Show CD Icon on, the status bar shows the CD name and an access lamp.

Many CD titles use floppy disks as well. When one asks for blank disks, make them with Disk > Create Blank Disk....

Music

CD audio (CD-DA) is mixed into the same output as the FM sound, following the fades the software asks for. In Immersive Audio, CD audio is not placed in 3D space; it plays in stereo from the centre.

Save States

A save state holds the drive's state, such as the play position, but not the CD itself. Loading one puts back the CD it was saved with, from the same place; if it is gone, the drive is left empty.

Known Limitations

  • Separated (8ch) recordings do not include CD audio.
  • The CD audio level and the length of a fade have not been measured on real hardware.
  • Seek times are not reproduced; data is read at normal speed (75 sectors a second).
