Cheats

Cheat codes in the 88PAR format (.pat) rewrite a game's memory.

Setting Up Cheats

Cheats are kept for the mounted disks, so mount the game's disk first.

ActionDescription
Cheats > PresetsPicks the game from the bundled code list (69 games)
Cheats > Import Cheat File...Reads a .pat file of your own

Disks are matched by file name, so all the disks in one file share the codes. An imported file's contents are stored in the app, so you can move or delete the original. Picking another preset or file replaces the current one.

Turning Cheats On and Off

Once cheats are set up, the Cheats menu lists their groups (such as 無敵, "invincible"). All groups start off; choose the ones you want to turn them on. Groups that are on apply every frame and stay on across launches.

Notes for each code appear under its group. Some codes only take effect under certain conditions, such as after a won battle, so read them first.

Cheats > Disable All Cheats turns every group off.

When the disks in drives 1 and 2 have different cheats, drive 1's are used.
