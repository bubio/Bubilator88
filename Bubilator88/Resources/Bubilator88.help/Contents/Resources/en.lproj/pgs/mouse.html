Mouse

Bubilator88 emulates the PC-8801 bus mouse (PC-8872), forwarding your Mac's relative mouse motion and left/right clicks to the PC-8801. Use it with drawing software and games that support a mouse or joystick.

Enabling

Turn on Settings > Mouse > Enable Mouse Input. It is off by default.

Mode

Choose how the mouse is read with Mode.

  • Bus Mouse (PC-8872) — Behaves as the genuine bus mouse. This is the right choice for mouse-aware drawing software.
  • Joystick (mouse-as-joystick) — Sends mouse motion as directional input, for games that read the OPN ports as a joystick.

Which one you need depends on the title. If one does not work, try the other.

Sensitivity

The Sensitivity slider scales movement (0.5x–3.0x, default 0.5x). In Bus Mouse mode it controls cursor speed; in Joystick mode it controls how readily a direction registers.

Capturing and releasing the pointer

While mouse input is enabled, click the emulation screen to capture the pointer. During capture the Mac cursor is hidden and locked, so motion is delivered to the PC-8801 without the pointer drifting off-window.

A mouse icon appears in the status bar while captured. Press Control+Esc to release; click the screen again to re-capture. Capture is also released automatically when the window loses focus.
