Getting Started

ROM Files

Bubilator88 loads ROMs from ~/Library/Application Support/Bubilator88/. This folder is created automatically on first launch.

Minimum Required File

FilePurposeNotes
N88.ROMN88-BASIC ROMThe app cannot start without this file.

Strongly Recommended Files

FilePurposeNotes
N80.ROMN-BASIC ROMIf it is missing, N-BASIC reads return 0xFF and boot can fail.
DISK.ROMSub-CPU disk ROMDisk access still works through a fallback path, but DISK.ROM gives more faithful behavior.
N88_0.ROM – N88_3.ROMN88 extension ROMsN88EXT0.ROM – N88EXT3.ROM are also accepted.

Optional Files

FilePurposeNotes
FONT.ROMFont ROMThe built-in ASCII font is used if it is missing.
KANJI1.ROMKanji ROM Level 1Used for Kanji display.
KANJI2.ROMKanji ROM Level 2Used for Kanji display.

Rhythm Sound WAV Files

To hear the YM2608 (OPNA) Rhythm part, place the following WAV files in the same folder. They must be signed 16-bit PCM. The app still runs without them, but the Rhythm part will be silent.

FileSound
2608_BD.WAVBass drum
2608_SD.WAVSnare drum
2608_TOP.WAVCymbal
2608_HH.WAVHi-hat
2608_TOM.WAVTom
2608_RIM.WAVRim shot
ROM files and Rhythm WAV files are copyrighted and are not included with Bubilator88. You must provide your own.

First Boot

After placing the ROM files, launch Bubilator88. ROMs are loaded on startup and again whenever you use Emulator > Reset.

To boot disk software, first insert a disk with Disk > Drive 1 > Mount... or Disk > Drive 1&2 > Mount..., then use Emulator > Reset (⌘R).

Boot Modes

Use Emulator > Boot Mode to select a mode. Changing it resets the emulator immediately.

ModeDescription
N88-BASIC V2Standard mode for SR and later. Most software uses this.
N88-BASIC V1HV1 high-speed mode. For software targeting models before the SR.
N88-BASIC V1SV1 standard mode. For software targeting models before the SR.
N-BASICPC-8001 compatibility mode. Uses N-BASIC ROM.

CPU Clock

Use Emulator > CPU Clock to switch between 8 MHz and 4 MHz. The setting is independent of Boot Mode, persists across launches, and is shown in the status bar.

Extended RAM

Choose a capacity from Bubilator88 > Settings > General > Extended RAM. Changes take effect on the next reset.

CapacityDescription
NoneNo expansion card installed. Software that probes for extended RAM will see an empty slot, just like an unexpanded machine.
128 KBEquivalent to one PC-8801-02N card. Default; sufficient for most titles such as Hydlide 3.
1 MBEquivalent to eight expansion cards. For the few titles that require 1 MB of extended RAM.
The original PC-8801-02N held 128 KB per card, with up to 4 cards (= 512 KB) supported by NEC. The 1 MB option corresponds to third-party high-capacity cards.

Monitor Type

Choose a setting from Bubilator88 > Settings > General > Monitor. This corresponds to DIP SW1-8 on real hardware: the monitor's horizontal frequency decides the vertical sync rate. Changes take effect on the next reset.

SettingDescription
24 kHz (Dedicated)Matches a dedicated PC-8801 display. 55.4 Hz vertical sync.
15 kHz (Standard)Matches a standard TV. 62.4 Hz vertical sync. Default.

Memory Wait

Toggle this at Bubilator88 > Settings > General > Memory Wait. This corresponds to DIP SW1-6 on real hardware: enabling it adds one wait state to main memory and text VRAM accesses, slowing the machine slightly. Off on a factory-default PC-8801. Changes take effect on the next reset.

Launch Arguments

An external launcher or a terminal can start Bubilator88 with a disk and a boot mode already selected. The argument format matches QUASI88: list options such as -v2 / -v1h / -v1s / -n (boot mode), -4mhz / -8mhz (CPU clock), -24k / -15k (monitor type), and -mem_wait / -mem_nowait (memory wait) alongside the path of the disk to open.

The same arguments can be passed through the URL scheme, one argument per arg item: bubilator88://boot?arg=-v1h&arg=… (paths must be absolute and percent-encoded).

For the full syntax, run /Applications/Bubilator88.app/Contents/MacOS/Bubilator88 -h in Terminal.
