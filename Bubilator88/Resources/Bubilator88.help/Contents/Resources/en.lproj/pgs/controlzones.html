Control Zones

Control zones let you play keyboard-only games with a mouse or a game controller. Clicking a zone on the screen types the keys registered for it, in order.

Turning Them On

Turn on Settings > Mouse > Enable Control Zones. Control zones are unavailable while Enable Mouse Input is on.

With Always Show Control Zones on, every zone is outlined. With it off, only the zone under the pointer and the one the controller has selected are outlined.

Pressing Esc or resetting stops keys that are still being typed.

Layouts

Zones are saved together as a layout, and each disk is assigned a layout; the layout of the mounted disk is used. When the disks in drives 1 and 2 have different layouts, drive 1's is used.

Layouts are managed under Settings > Mouse > Control Zone Layouts.

ActionDescription
New LayoutCreates an empty layout, assigns it to the mounted disks and starts editing it
Edit…Edits the selected layout. Double-clicking a layout does the same
Duplicate and Edit…Copies a preset, assigns the copy to the mounted disks and starts editing it
Import…Reads a layout from a .b88zones file

Duplicate, Export and Delete are in the menu that appears when you Control-click a layout.

Preset layouts are included for some games. Presets cannot be changed; use Duplicate and Edit… to make one your own.

Editing Zones

Emulation pauses while you edit, and menus and other operations are unavailable. Click Done when you are finished.

  • Adding a zone — Drag on the emulator screen.
  • Moving and resizing — Drag a zone to move it, or the handles of the selected zone to resize it. You can also type Position and Size in pixels of the 640 × 400 screen.
  • Registering keys — Click Record, then press the keys in order. Keys pressed together become one step. Steps are typed from the top down.
  • Detect Zones from Screen Text — Adds a zone for each line of text on the screen. A line that starts with a number also gets that key.
  • Disks Using This Layout — Use the disk icon to assign the layout to the mounted disks.

Mouse Buttons

Each mouse button other than the left one, and the wheel, can type one key wherever the pointer is on the screen. Change them under Mouse Buttons in the editor. The middle button stays turbo.

InputDefault
Right buttonSPACE
Button 4ESC
Button 5RETURN
Wheel up / downKeypad 8 / Keypad 2

Using a Game Controller

With Settings > Controller > Enable Game Controller and Use for Control Zones on, the D-pad and left stick move to the neighbouring zone, and the Confirm Button (X by default) types that zone's keys. While the mounted disk has control zones, these buttons cannot be mapped to keys.
