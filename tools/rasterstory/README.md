# RASTER STORY — 混在ラスタ表示の短編デモ

`rasterstory.d88` は PC-8801 用の起動ディスクです。`tools/vramtest` の U-1 と同じく、毎フレーム途中でグラフィック設定を **カラー200ラインから白黒400ライン** に切り替えます。上半分は夜の港と朝の資料室のカラー場面、下半分は漢字 ROM の字形で描く高精細な会話画面です。肖像は別に作成した白黒ドット絵です。添付画像はレイアウトの参考にし、絵と文章はこのデモ用に作りました。

## 起動と操作

24kHz モニタ設定の N88 V2 / V1S / V1H で、ドライブ 1 からディスク起動します。`KANJI1.ROM` が必要です（ディスクには含みません）。

- `1`: 今いる場面の机を調べ、下の文章を切り替える
- `2`: 今いる場面の窓を見て、下の文章を切り替える
- `3`: 港と明るい資料室を移動する
- `0`: 港の最初の場面と会話に戻る

キー入力は押した瞬間に一度だけ処理します。押し続けても画面更新は止まらず、割り当てのないキーでは何も変わりません。

初期画面: [`preview.png`](preview.png) ／ 資料室: [`room-preview.png`](room-preview.png)

上段は640×200のカラー200ライン表示（GVRAM上では640×100行を使用）、下段は640×400白黒モードの後半200行です。下段の文字は起動後にポート `$E8` / `$E9` から漢字 ROM の16×16字形を読み、Rプレーンへ等倍で描きます。**字形データはディスクに収録していません。** 15kHz では実機の400ライン表示に対応しません。

## ビルド

Python 3 と Pillow、ASL の `asl` / `p2bin` が必要です。`source-art.png` と `room-art.png` をアナログパレットに、`detective-art.png` を白黒肖像に変換して収録します。文章はビルド時に JIS コードから漢字 ROM アドレスへ変換します。

```sh
ASL_DIR=/path/to/asl-current python3 tools/rasterstory/build.py
```

`build/` にアセンブル中間ファイルを生成し、`rasterstory.d88` を更新します。`tools/vramtest/src/ipl.z80`、`lib.z80` と D88 書き出し関数を再利用しています。

400ライン白黒表示の下半分は R プレーンを使い、その領域は上半分のカラー絵と VRAM アドレスを共有します。パレットの `0/2`、`1/3`、`4/6`、`5/7` を同色にすることで、下半分の文字データが上半分の色を変えないようにしています。このため一つの走査帯では独立した4色です。上段を8つの走査帯に分け、表示中にアナログパレットを書き換えることで、512色中の **16色** を画面全体で使います。8MHz/4MHz で待ち時間を別に調整しています。
