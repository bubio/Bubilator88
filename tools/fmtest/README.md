# FMTEST — PC-8801 YM2608 (OPNA) サウンドテストディスク

vramtest と同じ構成（自前 IPL + メニュー起動）の、耳で確かめるための起動ディスクです。
vramtest が vraminfo.html の記述と pixel 単位で突き合わせるのに対し、こちらは
「実機のこの挙動、本当にこう聞こえるはずか」を確認するための道具なので、
`EXPECT` 表示はありません。判定するのは自分の耳です。

## 使い方

1. `fmtest.d88` をドライブ 1 に入れて、ディスクから起動します。
2. メニューで A〜C を押すとテストが始まります。
3. テスト中は ESC でメニューに戻ります。

## テスト一覧

| キー | 内容 |
|---|---|
| A | **レジスタ直叩きプレイグラウンド。** アドレス・値を2桁hexで入力して任意のOPNAレジスタに書き込み、即座に音で確認できる汎用ツール。SSG ($00-$0F)・FM ($30-$B6)・モード/タイマ ($24-$2B)・リズム ($10-$1D)・ADPCM ($00-$1B upper) など、チップの全アドレス空間に到達可能 |
| B | アルゴリズム&フィードバック聞き比べ（ch1）。同一4オペレータパッチのまま `$B0` だけを書き換え、ALGO 0-7・FB 0-7 をキーで切り替えながら持続音で比較 |
| C | CH3特殊モード（通常/効果音/CSM）。2026-09にYSが効果音モード ($27 D7:D6=01) を常用していると分かったが、実際は4オペレータへほぼ同じF-Numberを書いているだけで音色差がない、という調査結果を踏まえたデモ。モード2はYSが実際にやっていること（ユニゾン、音は変わらない）、モード3は同じレジスタ経路で意図的にオペレータを分散させた場合（不協和なコーラス）を聞き比べられる |

### A: レジスタ直叩きプレイグラウンドの操作

- `A`: 2桁hexでアドレス入力開始
- `D`: 2桁hexで値入力開始
- `RETURN`: 現在のアドレスに値を書き込み
- `U`: 下位バンク（`$44`/`$45`）⇔上位バンク（`$46`/`$47`）切り替え
- `1`-`6`: FMチャンネルN（4オペレータ全部）をキーオン
- `0`: 全チャンネル・SSG・タイマを無音化

レジスタの意味は `docs/develop/` 以下の資料や `X88000M/docs/SoundHardware.md`
（Yamahaのアプリケーションマニュアルを一次資料とした技術メモ）を参照してください。

## 制約 (v1)

- ADPCM・リズム音源の波形サンプル再生は含まれていません（サンプルデータの準備が
  別途必要なため）。プレイグラウンドからレジスタを直接叩くことはできます
- LFO (AMS/PMS) 専用のデモ画面はありません。プレイグラウンドで `$22`・`$B4`-`$B6` を
  直接操作してください

## ビルド

必要なもの: vramtest と同じ（ASL、Python 3）。

```sh
ASL_DIR=/path/to/asl-current python3 build.py      # → fmtest.d88
```

Bubilator88 の BootTester でスクリーンショット/音声を確認するには:

```sh
BOOTTEST_SCREENSHOT_PATH=/tmp/shot.ppm \
  BOOTTEST_KEY_EVENTS="130:B:tap" \
  BOOTTEST_AUDIO_WAV=/tmp/out.wav \
  swift run BootTester fmtest.d88
```

## 構成

vramtest からの流用/新規の内訳:

| ファイル | 役割 |
|---|---|
| `src/ipl.z80` | IPL。vramtest からそのまま流用（ディスク読み込みは汎用的） |
| `src/lib.z80` | CRTC/テキスト表示/キー入力/メニュー枠。vramtest からそのまま流用 |
| `src/main.z80` | メニューテーブル（vramtestの構造を踏襲、中身はFMTEST用に書き換え） |
| `src/t_fm.z80` | OPNAレジスタ書き込みヘルパーと A/B/C の各テスト本体（新規） |
| `build.py` | vramtest と同じビルドスクリプト（出力ファイル名のみ変更） |

メモリ配置・ビルド手順の詳細は vramtest の README を参照してください（同一です）。
