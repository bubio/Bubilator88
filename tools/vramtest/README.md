# VRAMTEST — PC-8801 テキスト/グラフィック VRAM テストディスク

「PC-8801 Programing - VRAM Information」
(http://mydocuments.g2.xrea.com/html/p8/vraminfo.html) に書かれた挙動を、
メニューから 1 項目ずつ確かめるための起動ディスクです。
各テストの画面には、ページに書かれた実機の結果を `EXPECT` として表示しています。

ページのプログラムは流用しておらず、記述をもとに書き起こしています。
ブートローダ（IPL）も自前のものです。

## 使い方

1. `vramtest.d88` をドライブ 1 に入れて、ディスクから起動します（N88 の V2 / V1S / V1H、15kHz / 24kHz のどれでも起動します）。
2. メニューで英字キー（A〜W）を押すとテストが始まります。
3. テスト中は ESC でメニューに戻ります。

メニューの 2 行目に、起動したモード・モニタ種別・クロックを表示します。

## テスト一覧

### テキスト / CRTC / DMAC

| キー | テスト | 内容 | テスト内のキー |
|---|---|---|---|
| A | 属性一覧（カラー） | 装飾 $00〜$07 × 下線/上線、8 色、反転色、セミグラフィック $00〜$FF と装飾 | — |
| B | 属性一覧（白黒） | 白黒モードの装飾とセミグラフィック。AT/SC の 4 設定を切り替え | 1〜4: AT/SC（2〜4 は行の読み方が変わり、画面が崩れるのが正常） |
| C | 属性の並びの規則 | 最初の属性は X=0 扱い、開始位置のソートと値の順番（ページの例）、色と装飾の独立、同じ開始位置の重複、行をまたいだ属性状態 | — |
| D | 40 桁モード | 奇数アドレスの文字、奇数 X の属性が無視されること | 1: 40×25 / 2: 40×20 / 3: 80×25 |
| E | 行数: CRTC とポート $31 | CRTC の行数とポート $31 bit5 の 4 組み合わせ | 1〜4 |
| F | 全画面反転 / カーソル / 点滅 | START DISPLAY の DM、カーソル形状 4 種、点滅間隔 4 段階、カーソル位置 | R: DM / C: 形状 / B: 点滅 / V: 表示 / 矢印: 移動 |
| G | 特殊制御文字 | 白黒トランスペアレントで行 12 に [$E0/$60][I/V/D] を置く。ステータスを常時表示 | 0: なし / 1: I / 2: V / 3: D / 4: $E0⇔$60 / 5: 割り込みマスク |
| H | CRTC ステータス / DMA TC | $51 と $68 の読み値、1 フレームあたりの TC2・UPDATE の検出回数、STOP DISPLAY 後の VE | S: STOP DISPLAY |
| I | DMA 開始アドレス | 開始アドレスを行単位で上下させて、$F3C8 の手前 8 行を見せる | SPACE: 停止 / 1: $0000 起点 / 2: $0001 起点（V1S のみ） |
| J | テキスト DMA と CPU 速度 | 同じループを表示中・STOP DISPLAY・DMA ch2 停止で計測（RTC 割り込みで計時） | SPACE: 再計測 |
| K | 27 色（V1S） | テキスト VRAM を $C000 に置き、DMA を 6000 バイトにして 2 画面を交互に表示 | — |
| L | 32 / 50 行セミグラフィック | 行数を増やして 2×3 / 2×2 ドット単位で色を付ける。色帯の 4 桁に $5A（市松）・$33（bit0,1,4,5）・$CC（bit2,3,6,7）・$FF を並べ、50 行で $CC の桁が消えること | 1: 32 行 / 2: 50 行（V1S） |

### グラフィック

| キー | テスト | 内容 | テスト内のキー |
|---|---|---|---|
| M | グラフィック/テキストの組み合わせ | ページの 6 通りの BASIC プログラム（テキスト白黒/カラー × カラー200 / 白黒200 / 白黒400） | 1〜6 |
| N | 白黒モードの背景色 | ポート $52（デジタル）と $54（アナログ、bit7=1） | 0〜7: デジタル / A: アナログ / W: 200⇔400 ライン |
| O | ポート $53 のプレーン非表示 | 白黒でのプレーン/テキスト非表示、カラーモード中に設定してから白黒に戻す場合（M88 の play6 の不具合） | 1〜4: 各ビット / 5: カラー⇔白黒 / 6: 200⇔400 ライン |
| P | 白黒グラフィック + テキスト属性の色 | 点灯ドットが文字セルの属性色になること、反転だけが効くこと、アナログパレットの反映 | A: アナログパレット / 4: テキスト非表示 |
| Q | 白黒モードで CRTC 停止 | CRTC を止めると点灯ドットがパレット 0 の色になる（ページの手順） | 1: カラー / 2: 白黒 / 3: 白黒 + CRTC リセット / 4: CRTC 再開 |
| R | ALU 自己判定 | 独立アクセス、$5C の読み戻し、ALU で選択が消えること、論理演算 4 種と組み合わせ、16 ビット書き込み、比較データ 8 色、3 プレーン転送、R→B / B→R、$FE80〜$FFFF、$35 bit7=0 でメイン RAM。15 項目をプログラムが PASS/FAIL 判定 | — |
| S | デジタル/アナログパレット | 色バー 0〜7 に各種パレット。デジタルモードでアナログ形式の 2 バイトを書く場合も | 1〜7 |
| T | ラスタパレット | 表示中にパレット 0 を何度も書き換える（デジタル 8 帯 / アナログ 32 帯） | SPACE: 切り替え |
| U | 表示途中の設定変更 | 画面の半分で 200→400 ライン、グラフィック OFF、$30 の 40 桁、$32 のデジタル→アナログ | 0〜4 |
| V | VRAM アクセス速度 | プレーン選択中の空ループ、$40 bit4 の標準/高速で 3 プレーン塗りを計測 | SPACE: 再計測 |
| W | システム情報 | 各ポートの読み値、DMA ch2 の読み戻し、CRTC パラメータ、テキスト VRAM が別バンクか | — |

## 注意

- L（32/50 行）や E（行数の食い違い）は CRTC に標準外の値を書きます。
  ページによると、実機ではモニタによって同期が数秒乱れることがあります。
- K、L の 50 行、I の $0000/$0001 はテキスト DMA を $F000〜$FFFF の外に向けるため、V1S でだけ動きます
  （ページの定義どおり V1H は V2 と同じ扱いです）。
- J、V の計測は RTC 割り込み（1/600 秒）で数えます。計測中はテキストが消えることがあります。

## ビルド

必要なもの:

- ASL（`asl` と `p2bin`、http://john.ccac.rwth-aachen.de:8000/as/ ）。Homebrew には無いのでソースからビルドします。
  macOS arm64 では `Makefile.def-samples/Makefile.def-arm-osx` を `Makefile.def` にコピーして `make` で通ります。
- Python 3

```sh
ASL_DIR=/path/to/asl-current python3 build.py      # → vramtest.d88
```

`ASL_DIR` を指定しない場合は PATH 上の `asl` / `p2bin` を使います。

Bubilator88 の BootTester でスクリーンショットを撮るには `shot.py` を使います
（例: `python3 shot.py r.png --mode n88-v1s R w120` で V1S 起動 → R → 120 フレーム後の画面）。

## 構成

| ファイル | 役割 |
|---|---|
| `src/ipl.z80` | IPL。トラック 0 セクタ 1。64K RAM モードに切り替えてから、本体をサブシステム経由で $4000 に読み込む |
| `src/main.z80` | 起動処理とメニュー |
| `src/lib.z80` | CRTC/DMAC 設定、テキスト表示、キー入力、RTC 計時、GVRAM 描画、パレット |
| `src/t_text.z80` | A〜L |
| `src/t_gfx.z80` | M〜V |
| `src/t_misc.z80` | W |
| `build.py` | アセンブルと 2D の D88 書き出し。IPL に読み込むセクタ数を渡す |

メモリ配置: 本体 $4000〜（上限 $BBFF）、作業域 $BC00、IM2 ベクタ $BD00、スタック $C000 から下。
N88 ROM モードでは $8000〜$83FF がテキストウィンドウになるため、IPL は読み込みの前に 64K RAM モードへ切り替えています。
